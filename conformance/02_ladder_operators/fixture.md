# constructed textbook-style derivation (paper-extraction shape; not extracted from a specific source — see header)
given ccr: [x, p] = i·ħ                                   from cited @qm-postulates
define a := (m·ω·x + i·p) / √(2·m·ħ·ω),  a† := (m·ω·x − i·p) / √(2·m·ħ·ω)
define H := p²/(2m) + ½·m·ω²·x²
assume ω > 0 and m > 0
assume H has a discrete spectrum with a lowest state |0⟩, H|0⟩ = E₀|0⟩ as lowest_state
derive comm(a, a†) from [ccr] | expand bilinearly: [mωx+ip, mωx−ip] = −i·mω·[x,p] + i·mω·[p,x] = −i·mω·iħ + i·mω·(−iħ) = 2mωħ, so [a, a†] = 2mωħ/(2mħω) = 1
derive H_in_ladder from [a, a†, H] | a†a = (m²ω²x² + p² + i·mω·[x,p])/(2mħω) = (m²ω²x² + p² − mωħ)/(2mħω), so ħω(a†a + ½) = p²/2m + ½mω²x²
derive commute_H from [H_in_ladder, comm(a, a†)] | [H, a†] = ħω·[a†a, a†] = ħω·a†·[a, a†] = ħω·a†
derive lower_H from [H_in_ladder, comm(a, a†)] | [a†a, a] = a†·[a, a] + [a†, a]·a = −a since [a†, a] = −1, so [H, a] = −ħω·a
derive ladder from [commute_H] | H(a†|0⟩) = a†·H|0⟩ + [H, a†]|0⟩ = (E₀ + ħω)·a†|0⟩; iterating, a†ⁿ|0⟩ has energy E₀ + n·ħω
derive ground_annihilated from [lower_H, lowest_state] | if a|0⟩ ≠ 0 then H(a|0⟩) = a·H|0⟩ + [H, a]|0⟩ = E₀·a|0⟩ − ħω·a|0⟩ = (E₀ − ħω)·a|0⟩, a nonzero state at energy below E₀, contradicting lowest_state; hence a|0⟩ = 0
    ? [domain conditions for this lowering argument, listed but not established here: |0⟩ ∈ dom(a) so a|0⟩ exists; a|0⟩ ∈ dom(H) so H(a|0⟩) exists; H|0⟩ ∈ dom(a) so a·H|0⟩ exists — this last follows from H|0⟩ = E₀|0⟩, |0⟩ ∈ dom(a), and linearity of dom(a), premises themselves unestablished; commutator identity valid on this state]
derive E0 from [H_in_ladder, ground_annihilated] | H|0⟩ = ħω(a†a + ½)|0⟩ = ħω·(0 + ½)|0⟩, so E₀ = ħω/2
derive bound from [H_in_ladder] | ⟨ψ|a†a|ψ⟩ = ‖a|ψ⟩‖² ≥ 0 so E ≥ ħω/2 — this bound alone does not determine E₀; saturation is established separately by ground_annihilated

    ? [that this sequence is the ENTIRE spectrum additionally requires the raising/lowering arguments with their domain conditions at every level, and that the tower exhausts the assumed discrete spectrum — not established here]

    ? [asserted conclusion, not derived here: the mapping from energy levels to observed spectral lines is outside this document, and no source is cited for it]

## Audit record (independent hand-check — this derivation IS the audit)

Every step re-derived from the starting points (`[x,p] = iħ` and the
definitions of `a`, `a†`, `H`); steps 4, 6 added by the Stage 2.1
correction review. None copied from an implementation or corpus text:

1. **[a, a†] = 1.** `[mωx+ip, mωx−ip] = −i·mω·[x,p] + i·mω·[p,x] =
   −i·mω·(iħ) + i·mω·(−iħ) = 2mωħ`; divided by `2mħω` ⇒ 1. ✓
2. **H = ħω(a†a + ½).** `a†a·2mħω = m²ω²x² + p² + i·mω·[x,p] =
   m²ω²x² + p² − mωħ`, so `ħω·a†a = p²/2m + ½mω²x² − ħω/2`; adding `ħω/2`
   recovers `H`. ✓
3. **[H, a†] = ħω·a†.** `[a†a, a†] = a†·(a·a† − a†·a) = a†·1`, so
   `[H, a†] = ħω·a†`. ✓
4. **[H, a] = −ħω·a.** `[a†a, a] = a†·[a,a] + [a†,a]·a = −a` (using
   `[a†,a] = −1`), so `[H, a] = −ħω·a`. ✓
5. **Ladder.** `H(a†|0⟩) = a†·H|0⟩ + [H,a†]|0⟩ = (E₀+ħω)·a†|0⟩`; induction:
   `H(a†ⁿ|0⟩) = (E₀ + n·ħω)·a†ⁿ|0⟩`. ✓ (valid for the generated tower;
   per-level domain conditions — see open item below.)
6. **Ground-state annihilation (the corrected step).** If `a|0⟩ ≠ 0`,
   then `H(a|0⟩) = a·H|0⟩ + [H,a]|0⟩ = (E₀ − ħω)·a|0⟩` — an eigenstate
   strictly below `E₀`, contradicting `lowest_state`. Hence `a|0⟩ = 0`. ✓
   *Conditional on the domain items listed in the `?` — recorded as open,
   not as satisfied.*
7. **E₀ = ħω/2.** From step 2 and step 6: `H|0⟩ = ħω(a†a + ½)|0⟩ =
   (ħω/2)|0⟩`. ✓ (no longer assumes anything about `a|0⟩ = 0` existence —
   it is derived in step 6, subject to the same open domain items.)
8. **Bound (consistency check).** `⟨ψ|a†a|ψ⟩ = ‖a|ψ⟩‖² ≥ 0` ⇒
   `E ≥ ħω/2`. Saturation does **not** follow from this bound alone —
   that is why step 6 is needed. ✓
9. **Induction.** `Eₙ = E₀ + n·ħω = ħω(n + ½)` for the generated tower. ✓
   *Exhaustiveness of the tower over the whole spectrum is an open item
   (see `spectrum`'s `?`).*

## Rationale

Tests the corpus's heaviest derivation path: imported postulate,
definitions, derived lemmas, a named assumption, localized `?`s, an
inductive conclusion, and a claim whose bridge is unresolved. Its golden
label was **earned by in-stage independent checking, then re-checked after
a defect review** — the original version derived only a lower bound while
claiming the full spectrum, and its `?` misdescribed the document's own
structure (asserted a premise the `assume` line never contained). The
repaired fixture keeps the historical gap visible as the `bound`
teaching-point step: *a correct inequality does not imply the saturated
value.* This fixture is the corpus's standing evidence that structure +
provenance + an audit record can still hide a missing mathematical
inference — and that annotations must describe dependencies, not invent
premises.

## Negative cases

**N1 — derivation laundering (ANTI-PATTERN):**

```text
given spectrum: Eₙ = ħω(n + ½)   from cited @textbook
derive spectrum_again from [spectrum] | [the above derivation, inline]
```

Must be flagged: a `given ... from cited` used as the premise of a `derive`
whose reasoning restates the cited content does not produce an independent
derivation; it duplicates. The honest forms are `given` (import) or
`derive` from the actual primitives (`ccr`, definitions).

**N2 — status smuggling (ANTI-PATTERN, I3):**

```text
claim E: PROVEN spectrum Eₙ = ħω(n + ½) confirmed by experiment
```

Must be flagged twice over: `PROVEN` is an unauthorized status word, and
"confirmed by experiment" asserts empirical support the document never
represented — ancestry is not support (I2), even when the ancestry is real.
